# Bounded Sail player finalization

`cellSailPlayerFinalize`, NID18B4629D, now resolves a live player by guest effective address and uses the existing descriptor teardown gate and ownership policy. Missing players return INVALID_ARG (80610701). Registered descriptors or a descriptor callback in progress return INVALID_STATE (80610702), leaving all records and allocations intact. Successful teardown releases unregistered descriptor files and guest metadata through each allocation's retained free callback exactly once, then invalidates the player. Guest player bytes are not erased and no events or decoded frames are produced.

This is a conservative local HLE policy, not a reconstruction of firmware teardown. The original MAG retail v1.0 ELF, SHA2560089f0d6d17e48533ce7ff8d943dddd03487b925e7b04a1a055bfb907568694c, calls Finalize(movie+80) at3C6700, LR3C6704. Its cleanup routine ignores the return and proceeds to adapter/container cleanup. The .pam startup path creates, configures and registers a descriptor at3CD6B4/3CD6CC/3CD6D8. The guest destroys a descriptor on queued event major5 at3D297C; current OpenStream/CloseStream placeholders do not generate descriptor events major4/5. Thus this change registers the missing call but does not complete MAG's registered descriptor lifecycle. A registered-descriptor refusal must remain visible in native logs; it must not be called successful media cleanup.

The source branch is stacked on fix/sail-allocator-lifetime (525377ba), which retains allocator callbacks before the caller's stack table expires. Decoder support, asynchronous event lifecycle, adapter registration, legacy player initialization capacity/duplicate handling and general player API concurrency remain outside this patch.

The regression uses the real Sail implementation, generated NID registration and PPU HLE bridge. It verifies handler registration, invalid player arguments, registered refusal with unchanged guest bytes/count/allocation, isolation from another player's finalization, real local PAMF allocation, retained free identity after allocator/table reuse, free-callback reentry refusal, exact-once cleanup, stale descriptor/player rejection and slot reuse. The runner accepts an optional local PAMF path; no game bytes are committed.
