# Optional retail ATRAC3+ audio for timed Sail video

The explicit `PS3RECOMP_SAIL_ATRAC_AUDIO=1` diagnostic complements the existing bounded THX/MAG intro video profiles when built with verified FFmpeg 9. Real audio PCM advances the retail client's original audio-driven movie clock. Without this opt-in, sound GetFrame continues to return NO_FRAME.

The selected descriptor audio ES must be ATRAC3+ private PES track0..9. Demux parses top-level program packets and skips other PES payloads, so byte patterns inside video cannot become false audio packets. The original three sound callbacks are retained: makeup(arg), cleanup(arg), formatChanged(arg, temporary24-byteformat,session). The game allocator receives(arg,128,size); its free receives(arg,128,buffer). Scratch holds2048 interleaved samples. GetFrame overwrites scratch at the next invocation; no separate sound frame release exists. EOF hides delivery; stream close dispatches cleanup and frees scratch. Uncertain allocator or callback ownership remains quarantined.

No game UI event, state or movie-clock field is patched.
