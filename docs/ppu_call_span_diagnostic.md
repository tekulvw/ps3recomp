# Bounded selected PPU dispatch spans

This private native diagnostic extends the existing default-off audio chronology. `AUDIO_CHRONOLOGY_PPU_TARGET` selects one aligned nonzero 32-bit guest code address (for example, synthetic `0x12000`). It also requires the existing valid `AUDIO_CHRONOLOGY=1`, trigger, duration and limit configuration. No address or game identity is compiled into production code.

Only the audio poll admits the trigger. The call stream shares the exact audio clock, start/deadline and record limit, and enabling a valid selected target caps that shared capture window at ten seconds. It uses a separate statically reserved32768-entry metadata ring (128B per record,4MiB); inactive paths do not touch its records. Existing audio record kinds/format/prefix are unchanged, so the existing audio assessor can retain its separate scope.

`[ppu-call-span-summary]` reports the shared `run_id=start_us`, selected target, count, dropped records and `pending_recorded_brackets`. `[ppu-call-span]` records contain sequence, run/token IDs, phase0start/1end, monotonic microseconds, host context identity, full64-bit guest thread ID, target, selected-call nesting depth, flags and raw entry r3..r10/r31. End records repeat the entry arguments, not the return register values. These integers authorize no guest-memory or PCM dereference.

The source span begins immediately before the actual `fn(ctx)` and completes only after every `g_trampoline_fn` continuation in that dispatch has drained. Nested selected dispatches receive separate tokens and depth. End flag0 means that PPU dispatch span returned through this normal boundary; it does not mean an asynchronous SPU job completed. Flag1 records C++ scope unwinding before normal completion. Signals, abort, longjmp, process termination or deadline crossing can leave a recorded start without an end. Pending brackets are not an exact physical in-flight count. Dropped or incomplete spans cannot be used as complete callback cadence evidence.

The hot begin hook checks active admission and selected target before taking a clock/metadata lock or reading context fields; it independently checks the hard deadline before context reads. After expiry/postflush it uses no clock, lock or context reads. The first discovery of a passed deadline may take one clock/metadata lock to disable admission. A callback ending after deadline is not assigned a fabricated boundary time. The end hook uses only its frozen token metadata. No lock is held across guest dispatch/trampoline execution. Public hooks preserve errno and Windows last-error state. No per-call output occurs; bounded printing happens only at audio window/shutdown flush, outside the measured window.

The default-off hook adds a function/atomic-admission check and small scope bookkeeping; it does not promise cycle-identical performance. While active, inclusive durations also include diagnostic metadata/lock overhead. Callback flags and argument cohorts must be evaluated per record: a separate entry snapshot does not prove all later callbacks use the same flags. Register values, nonzero audio metadata and absence of a recorded producer do not establish guest intent, audibility, ownership or CPU-writer absence.

Existing `PS3_ICALL_GATE` was considered first. It has a polled file/histogram and returned-zero counts, not paired start/duration/arguments on this clock, and its optional trace prints on the hot path. It does not answer this diagnostic question.

Validation: `python3 tools/test_ppu_call_spans.py [--sanitize]` extracts the exact production fn/trampoline block into synthetic work. Cases cover a100us function plus200/300us continuations (600us inclusive), nested1150us span, exception propagation, poisoned-context inactive/expired/postflush paths, record cap,8 concurrent producers, deadline crossing, pending flush, invalid/missing target and ten-second cap. Parent source fails the actual span-record assertion. `tools/test_audio_chronology.py` retains15 actual-DMA/cellAudio/linkage cases. No application, audio device or game is controlled by these fixtures.
