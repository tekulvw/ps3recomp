# Bounded Metal draw and target evidence

Enable `PS3RECOMP_METAL_DRAW_DIAGNOSTICS=1` to capture the first32 queued draw records and RGB statistics for the first8 command submissions touching color targets after drawing starts. The flag is off by default. The diagnostic works on the dispatch backend and includes guest-reference flushes before presentation; the existing presentation-only sampling cannot account for these earlier submissions.

Each queued draw logs pipeline identifier, vertex/index counts, stride, color target handles, depth handle, texture unit0 handle, viewport/scissor, first staged vertex's first16 bytes interpreted as host floats, and constant-buffer byte counts. The first vertex sample is a raw observation; it is not guaranteed to be position data or transformed coordinates. A queued record does not prove a successful draw: absent/invalid pipelines may still be skipped by the encoder. Shader sources can be captured separately with `PS3RECOMP_METAL_SHADER_DUMP` pointing to an existing directory.

The target sampler includes up to16 unique color handles touched in a submission, plus the selected presentation surface when it fits that bound. It waits for that command buffer only when sampling is enabled and its budget remains. It then reads supported shared-storage RGBA8/BGRA8 textures, reporting size, format, command-buffer status and RGB statistics. Alpha alone does not make a surface nonblack. Unsupported formats/storage modes (including managed storage, which needs a separate GPU-to-CPU synchronization), failed GPU submissions, excessive sizes and allocation failure report rgb_available=0. These are statistics, not images and not evidence that a surface was displayed.

Target reads occur before retired objects are collected. The diagnostic neither changes commands nor creates replacement surfaces or shaders. Its bounded waits change timing; repeat without the flag when investigating timing-sensitive behavior. Budgets are process-wide; no per-frame completeness is claimed. More than16 touched handles may leave later surfaces unobserved.

The real Metal regression first failed because diagnostic records were absent. It now verifies opt-in silence,32-draw and8-submission budgets, target identity, first staged vertex bytes, CPU-seeded color, a GPU clear from black to green, and alpha-only pixel statistics and completed GPU status. The fixture uses seeded textures and absent draw pipelines, so it validates diagnostic observation without claiming shader or draw correctness. Existing presentation and first-nonblack capture regressions also pass on macOS.
