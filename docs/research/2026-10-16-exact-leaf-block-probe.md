Goal: correctness-preserving progress toward30 verified displayed gameplay FPS, with muted host output and guest audio intact. The user explicitly requested autonomous native trials and a quick efficacy screen before extended review. This is a default-off probe, not an accepted architecture or a change to legacy whole-image admission.

The next hypothesis is that whole-image admission overwhelms savings from compiled small bodies.

Add a separate registry for independently translated instruction spans. Each permitted block contains no guest calls, channel operations, stops/halts, IRQ control/returns, fences or FPSCR writes. Direct and indirect branches are lowered as raw architectural PC transfers; no return-register, caller, function-classifier or outside-code fact is used. Ordinary ALU/LS operations reuse the existing stateless instruction lowering/shared helpers. Cross-block transfers retain the runtime dispatcher/checkpoints and actual outer call-drain return boundary. No bare-return service adapter is introduced.

Each lookup and function entry compares every expected byte of the complete block, with no cached trust. Eligibility requires the original policy, private local store, RUNNING status, and no pending enabled interrupt or saved/armed IRQ frame. Ambiguous matches reject. Existing verified-image-owned immutable storage supplies expected bytes; registry storage is bounded and startup-only. Existing native functions keep their original whole-image admission. Changes outside an independent block cannot alter its translation; any later destination receives its own original admission or interpretation. Mid-block SMC retains the existing readonly-running-body limitation.

Implement inline in this isolated SDK worktree: first a real-runtime registry/changed-byte/nested-return fixture and requested-compare-byte check; then the bounded registry/lookup and separate stateless emitter; compare a neutral generated loop to the real interpreter. Run focused optimized/UBSan checks, preserve source/build pins, then a same-binary muted native screen with legacy audio B enabled in both arms.
