# Connected SPU regions

Goal: preserve MAG retail v1.0 execution while advancing toward sustained >=30 verified displayed FPS, stretch60–120. Native tests mute launcher/engine via SDL_AUDIODRIVER=dummy and retain guest audio/SPU work. Existing callback rates alone cannot satisfy displayed-FPS acceptance.

User authorizes autonomous implementation/testing and explicitly requests not stopping before the performance goal. This design implements the requested region direction; it does not claim that one region trial is sufficient to reach30FPS.

Architecture: retain original logical function bounds, return classification, arithmetic and native-call brackets. Group adjacent supported logical bodies into bounded physical regions, with original public wrappers and entry dispatch for each proven instruction PC. Original direct calls retain explicit return-PC drains. Every external admission retains exact whole-image ownership validation and every original body entry retains its complete exact span gate. Code mutation between bodies still rejects the affected code. Unsupported words and gaps never become executable no-ops.

Internal direct edges that previously queued a trampoline may run a local checkpoint and goto the destination body. Local continuation is eligible only while interrupts are disabled, host_depth is zero and drain_ret_pc is zero; enabled-interrupt edges and tail-return compatibility mode queue the original target and return, preserving existing nested IRQ frames. Local checkpoints retain lockstep and task/stack-reset checks once per original boundary. Diagnostic-PC history behavior must be explicit; diagnostic modes that cannot be reproduced exactly deopt to the dispatcher. No scheduling checks are removed to manufacture a gain.

All original registered entry function identities are preserved. Interior-PC entries use a per-region dispatch wrapper, with exact admission. Registry capacity is counted and overflow rejected before emitting. Entry dispatch never changes instruction decoding or assumes an arbitrary plain branch is an ABI call.

Correctness evidence: neutral programs compare legacy lifts, regions and interpreter architectural state, local store, stop/return PCs and channel outcomes. Cover direct/conditional loops, fall-through, direct/non-r0/indirect calls, multi-entry resumes, interrupt-enable/disable windows and nested IRQ unwind, between-body code mutation, unsupported instructions/gaps, scheduling/stack reset and bounded fallback. Record semantic hook counts where meaningful. Optimized and UBSan controls precede native testing; ASan host startup is currently unavailable and separately qualified.

Evidence: Yakuza-Dead-Souls-EX fd2cff9442dc6f5b977c6c4705dc483c060f1682 demonstrates physical regions with per-PC entries; its IRQ/verification contracts are weaker and are not adopted. RPCS3 7b4de2f13dfe6da28129e2e5905dca79c87cfde8 demonstrates connected SSA regions. MAG exact generated body medians are11 audio/9 geometry instruction slots; static frequency is not dynamic cost. Ghidra12.1.4 has no installed SPU processor, so original SPU CFG evidence uses pinned decoder/bytes unless a verified provider is located. Never mis-import SPU as PowerPC.

Native protocol: exact same binary and matched training scene, original quiet control plus strongest region candidate, flags/provenance pinned, no active owner conflict, host output muted, no raw pixel/data capture during timing. Correlate unique guest frames, actual submission, successful completion and positive drawable timestamps for final30FPS acceptance. Check graphics/output separately. GPU-report synchronization is a parallel critical-path lead; preserve completion-before-buffer-reuse ordering.

Pre-native verification: six planner/emission/compiler cases pass. All six supported PCs execute to matching full GPR/PC/LS state at depth0/1 and IRQ0/1 (48 runs), O2 and UBSan. Real nested r6/r7 calls and full interpreter fallback preserve the original explicit0x10004 stop PC after conservative framed-edge deoptimization. A delegated real checkpoint mutating destination bytes rejects at the original0x10008 PC and executes changed bytes through the full interpreter; IRQ/frame/drain-return deopt leaves context and pending frame unchanged. Existing verified-span suite1181checks and encoded D/E branch suites184/270cases pass. Regenerating legacy geometry source is byte-identical to the pinned source after include-path normalization. No native speedup is established by these checks.
